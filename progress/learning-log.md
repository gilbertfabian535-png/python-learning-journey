Concepts learned

- While loops

- Basic state management

Features implemented

- Start and stop the car.
- Check the car's status.
- Restart the engine.
- Display instructions.
- Quit the simulator.

Lessons from debugging

1. A Boolean variable can maintain the program's state between commands.
2. Initialising variables outside a loop allows them to retain their values.
3. "break" exits a loop.
4. "continue" skips the remaining instructions in the current iteration.
5. The restart feature changes the state to stopped and immediately back to running.
